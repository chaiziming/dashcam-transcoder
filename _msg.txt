修复 CI 构建失败：Inno Setup 安装方式

首次 CI 运行在第3步「安装 Inno Setup」失败（exit code 1，43 秒就挂了，
根本没走到下载 ffmpeg）。

原因：choco install innosetup 首次运行需要先下载软件源，
受网络/代理/权限影响容易失败，且装完 ISCC 的实际路径随版本变化。

改为直接下载官方安装器静默安装，路径固定可控：
- 下载官方 innosetup-6.7.3.exe
- /VERYSILENT 静默安装
- 按候选路径查找 ISCC.exe，都找不到则全盘搜索兜底
- 通过 GITHUB_ENV 传给后续步骤

顺带加固（原来失败会静默往下跑，白等几分钟且看不出哪步错）：
- 每个关键步骤加 LASTEXITCODE 检查并 exit 1
- 编译后确认安装包真的产出
- actions/checkout 升到 v5（Node 20 弃用警告）

已本地实测：含空格路径 + /D 参数 + 完整编译通过（ExitCode 0）。
